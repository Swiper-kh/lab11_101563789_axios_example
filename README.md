# Lab11 - Working with Axios and Fetch API

COMP 3123 - Full Stack Development I
Student ID: 101563789

React app that fetches 10 random users from https://randomuser.me/api/?results=10 and displays them with React Bootstrap.

- `src/components/PersonList.jsx` - fetches data with **Axios**
- `src/components/PersonListFetch.jsx` - fetches data with the **JS Fetch API**
- `src/components/PersonCard.jsx` - displays one user

## Run

```
npm install
npm start
```
